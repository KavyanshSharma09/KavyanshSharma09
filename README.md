## Projects

**[Verses1](https://github.com/KavyanshSharma09/Verses1)**
Live coding battle platform where users compete on code efficiency, not just correctness. AST-based analysis (Big-O, Halstead metrics, security checks), 68-problem bank with hidden test cases, 1v1 battle lobbies, Google OAuth, Supabase/PostgreSQL, and a keep-alive daemon against free-tier cold starts.
`Python` `Django` `PostgreSQL` `Supabase` `OAuth`

**[Graph-Memory-Harness-for-Local-LLMs](https://github.com/KavyanshSharma09/Graph-Memory-Harness-for-Local-LLMs)**
Graph-based memory layer for locally run language models.
`Python` `LLM` `Graphs`

**[colab_agent](https://github.com/KavyanshSharma09/colab_agent)**
An agent built for Google Colab workflows.
`Python` `Colab`

**[identity_grounding_finetune_result](https://github.com/KavyanshSharma09/identity_grounding_finetune_result)**
Results from an identity-grounding fine-tuning experiment.
`Python` `Fine-tuning`

**[CrashGuard](https://github.com/KavyanshSharma09/CrashGuard)**
Vehicle crash detection with a fine-tuned TensorFlow model and a Tkinter desktop app for webcam and video input. Saves evidence images and video, keeps a JSONL incident log, and sends email and SMS alerts. F1: 92.3% daytime highway, 84.8% night, 93.6% recorded video.
`Python` `TensorFlow` `OpenCV` `Twilio`

**[PyOptimizer](https://github.com/KavyanshSharma09/PyOptimizer)**
Static analysis tool that finds CPU bottlenecks in Python and recommends CuPy GPU alternatives. Measured 40% execution speed increase on benchmarked workloads.
`Python` `CuPy` `NumPy`

**[runfn](https://github.com/KavyanshSharma09/runfn)** ([PyPI](https://pypi.org/project/runfn/))
Open-source CLI and importable library that runs a function from a file without throwaway scripts. Detects parameters automatically, validates return values with `--expect`, and times execution with `--time_it`.
`Python` `CLI` `PyPI`
